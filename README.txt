МОЯ ЖИЗНЬ — Android Studio project

Это исходный проект Android-приложения с офлайн 2D life-sim игрой внутри WebView.
Это НЕ готовый APK-файл: APK нужно собрать в Android Studio.

Как собрать:
1. Распакуй ZIP на компьютере.
2. Открой Android Studio → Open → выбери папку MoyaZhizn.
3. Дождись Gradle Sync.
4. Если Android Studio предложит установить Android SDK Platform 35, согласись.
5. Build → Build Bundle(s) / APK(s) → Build APK(s).
6. APK появится в app/build/outputs/apk/debug/app-debug.apk

Эмулятор не нужен. Для установки на телефон передай APK на Android и открой его.
Игра работает офлайн и сохраняет прогресс на устройстве.
